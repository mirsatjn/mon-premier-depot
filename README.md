# La Forêt Oubliée

Jeu d'aventure textuel pour mobile (React Native / Expo).

## Lancer
```
npm install
npx expo start
```
Scanne le QR code avec l'app **Expo Go** (iOS / Android).

Les scènes sont dans `src/story.js` : ajoute-en pour agrandir l'histoire.
La progression est sauvegardée automatiquement.
